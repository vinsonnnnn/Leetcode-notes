# LeetCode Hot 100 · Python

[中文介绍](#中文介绍) | [English](#english)

## 中文介绍

### 项目简介

这是一个使用 **Python** 练习 **LeetCode Hot 100** 的个人学习项目。每道题按题号整理学习笔记和代码答案，记录解题思路、算法实现以及相关知识，方便学习与复习。

题目和笔记持续更新中。

### 每题包含什么？

| 文件 | 内容 |
| --- | --- |
| `.md` 学习笔记 | 题目说明、完整解题思路、Python 答案、示例推演、时间与空间复杂度、边界情况和易错点 |
| `.py` 代码答案 | 对应题目的 Python 解答，便于阅读、练习和提交 |

笔记还会说明题目标签中的知识具体用在什么地方，例如哈希表、双指针、滑动窗口、前缀和、动态规划和矩阵操作，并对关键 Python 语法进行解释。

### 文件组织

文件按“题号 + 题目名称”命名，笔记与答案放在项目根目录。例如：

```text
Leetcode-notes/
├── README.md
├── 1.两数之和.md
├── 1.两数之和.py
├── 160.相交链表.md
├── 160.相交链表.py
└── ...
```

可以从 [160.相交链表的学习笔记](./160.相交链表.md) 和 [Python 答案](./160.相交链表.py) 开始查看。

### 如何使用

1. 按题号找到对应的 Markdown 笔记，理解题目与解题思路。
2. 阅读 Python 答案，结合示例观察算法如何执行。
3. 尝试独立实现，再对照笔记检查复杂度和边界情况。
4. 将解答提交到 LeetCode 验证，并记录自己的理解与疑问。

## English

### About

This is a personal learning project for practicing **LeetCode Hot 100** in **Python**. Each problem is organized by its problem number, with study notes and a Python solution to document the reasoning, implementation, and related concepts for learning and review.

Problems and notes are added and updated over time.

### What does each problem include?

| File | Contents |
| --- | --- |
| `.md` study notes | Problem description, detailed reasoning, Python solutions, example walkthroughs, time and space complexity, edge cases, and common mistakes |
| `.py` solution | The corresponding Python implementation for reading, practice, and submission |

The notes also explain where the concepts behind each problem's tags are used, such as hash tables, two pointers, sliding windows, prefix sums, dynamic programming, and matrix operations. Key Python syntax is explained where helpful.

### Repository structure

Files are named using the problem number and its Chinese title. Notes and solutions are stored together in the repository root. For example:

```text
Leetcode-notes/
├── README.md
├── 1.两数之和.md
├── 1.两数之和.py
├── 160.相交链表.md
├── 160.相交链表.py
└── ...
```

Start with the [notes for Problem 160: Intersection of Two Linked Lists](./160.相交链表.md) and its [Python solution](./160.相交链表.py).

### How to use

1. Find a problem by its number and read the Markdown notes to understand the task and approach.
2. Read the Python solution and follow the example walkthroughs.
3. Implement the solution yourself, then review its complexity and edge cases using the notes.
4. Submit the solution to LeetCode for validation and record your own observations and questions.
